# BulkRNA V2.0.0发布说明

发布日期：2026-10-28，Asia/Shanghai。源码版本2.0.0，配置格式仍为1.0-review，Git发布分支main，标签v2.0.0。GitHub目标：https://github.com/kezhang376-lang/BulkRNA。

## 发布范围

结果根目录为output_dir/run_id，不再有runs层。整个Shell阶段使用bam_count_data，整个R阶段使用gene_expr_data，差异结果使用gene_diff_expr。运行包目录、压缩包及结果目录同名，格式v<版本>_<YYYYMMDD>_run<至少两位正序号>。

标准流程包含PE fastp、STAR、samtools检查/索引、featureCounts、MultiQC、样本QC、DESeq2 pairwise Wald、GO ORA/GSEA及HTML报告。

本次项目专用R依赖队列位于projects/20261027_xiehe_zhou/orchestration/queue_R_after_shell.py，并冻结到实际运行包中。在R Pod后台读取共享Shell状态，成功且产物/输入检查通过后调用原R启动器；Shell失败或等待48小时超时则停止，不重试。此项已通过真实衔接，不表示每个新项目都会自动生成同类脚本，也不等于通用跨Pod调度器或断点恢复。

## 实际验证

运行v2.0.0_20261028_run01，2组各3样本，10GY5FFRT相对Control。Shell于北京时间02:02:18成功，R于02:06:30成功。

- 6个BAM及索引通过检查，57010基因×6样本计数矩阵与Assigned总计一致。
- 实际模型~group、parametric，过滤后23269基因，上调621、下调231。
- 原始计数、完整及显著差异表与V1 SHA256一致；新布局和报告41个文件链接通过。
- GO GSEA显著157条，上调ORA419条，下调ORA27条；8条GSEA通路统计量NA、约2.34%排序ties、部分P值低于eps=1e-10。均保留并记录，没有为消除警告改参数或重跑。
- 既有Python19项测试通过；R模拟测试覆盖命名、布局、计数、模型、报告、Shell→R输入以及不覆盖。发布前新增中文说明编码回归检查，结果见发布验证记录。

原始证据在logs/v2.0.0_20261028_run01/completion_report.md及对应JSON。流程验收不替代生物学解释；NA通路不作可靠检验结果解释。
