测试时发现并修正了 JSON schema 闭合、中文 YAML 在 Windows C locale 下的读取、YAML序列被简化导致类型丢失、生成 Bash 入口 CRLF、DESeq2 自动变更拟合方式接受检查等问题。

GO smoke test 为节省时间显式使用 eps=0.001，软件提示部分通路 p 值可能更小；这是人工测试的精度边界提示，没有自动调整参数。配置示例的 eps 是另一数值，正式分析需单独确认。R 启动时有 C.UTF-8 locale 警告，treeio 有方法注册消息；测试最终退出成功。中文配置读取已单独修复，尚未验证所有中文路径/图形字体场景。
